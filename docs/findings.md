# Findings

Every defect, review finding, and process failure gets a row here **before** it is fixed.
A row names where the evidence came from; "the code looks right" is not evidence.

**Status vocabulary:** `open` · `fixed: <commit>` · `not reproduced: <what was tried>` ·
`left as is: <why>` · `planned` · `tabled`.
**Confidence:** `confirmed` (reproduced, or shown with real data) · `likely` (code path traced
end to end, not reproduced) · `possible` (plausible, unverified).
**Owner decisions** are marked *(owner, date)* and are not reopened without a new fact.
